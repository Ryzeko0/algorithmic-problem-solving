# Algorithmic Problem Solving

My progression in algorithmic logic using **Python**, through the exercises of [France-IOI](https://www.france-ioi.org/).

This repository documents my self-directed training as part of my transition towards a **mathematics and computer science** curriculum. Each exercise is solved by myself and starts with an `# Objective:` comment describing what the program does.
